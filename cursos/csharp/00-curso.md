### Descripción

Aprendé **C# desde cero**. No hace falta saber programar: cada tema se explica con ejemplos, antes de pedirte nada, y avanzás de a un paso por vez. C# es la lengua de **Unity** y de **Godot**, y una de las más pedidas para programas de escritorio y servidores.

Todo se hace **acá mismo, en tu navegador**: escribís, tocás *Ejecutar* y ves qué pasa. No tenés que instalar nada. La primera vez tarda unos segundos en cargar y después es instantáneo.

Acompañás a **Ceci**, una violinista de la Feria de las Luces que toca de oído y nunca leyó una partitura. Llega al **Conservatorio de Do Sostenido** con una cajita de música que suena rara, y su directora, **Clave**, le pone una sola condición: *«Acá la magia se escribe y se ensaya antes de sonar.»*

Cada tema es un **nodo** del árbol, con **micro-misiones** que se comprueban solas. Las más importantes te dan **corcheas**, la moneda del Conservatorio, para abrir el nodo siguiente.

> Qué hace falta: nada más que este navegador. Si después querés programar en tu compu, en Windows o en Linux, el mismo código corre con .NET 10.

### Crónica

Ceci llega al Conservatorio con el violín al hombro y la cajita de música colgada del cinturón. Hay torres con tubos de órgano y aprendices que escriben partituras en vez de tocar. Intenta tocarle la melodía a la Directora, de oído.

—No —dice {mentor}, sin levantar la voz—. Acá la magia se escribe y se **ensaya** antes de sonar. Si la partitura tiene un error, no hay concierto. Sentate. Empezamos por una sola nota.

Al lado de Ceci, un chico con un tambor le sonríe. Se llama **Bemol**, y sobre su atril duerme un gecko de luz cian: **Gheco**.

### Objetivos

- Escribir y ejecutar tu primer programa en C#.
- Mostrar texto con `Console.WriteLine` y `Console.Write`.
- Entender que las órdenes se ejecutan de arriba hacia abajo.
- Leer un error del compilador sin asustarte.

### Antes de empezar

Nada. Este curso arranca de cero.

### Explicación

#### ¿Qué es un programa?

Un **programa** es una lista de órdenes que la compu hace una por una, de arriba hacia abajo. Se parece a una partitura: alguien la escribe, y después se toca.

**C#** (se lee «ce sharp», y en música es *do sostenido*) es uno de los idiomas en los que se escriben esas órdenes.

#### Tu primera orden

```csharp
Console.WriteLine("Hola");
```

Vamos por partes:

- `Console` es la **consola**: la ventana donde tu programa muestra cosas.
- `WriteLine` quiere decir «escribí una línea».
- Lo que va entre paréntesis es lo que tiene que escribir.
- Las comillas `" "` marcan dónde empieza y dónde termina el texto. No se ven en pantalla.
- El `;` del final es como el punto de una oración: **toda orden termina en `;`**.

#### El ensayo general: el compilador

Antes de ejecutar tu programa, un ayudante lo lee entero: el **compilador**. Si encuentra un error, **no se ejecuta ninguna línea** y te avisa dónde está. Es el ensayo general de Clave: mejor que el error aparezca acá y no delante del público.

Un error se lee así:

```
Programa.cs(2,26): error CS1002: Se esperaba ;
```

Quiere decir: en el archivo `Programa.cs`, **línea 2**, columna 26, falta un `;`. No hay que entender todo: alcanza con mirar **la línea** y leer el mensaje.

#### Mayúsculas y minúsculas

C# las distingue: `Console` funciona y `console` no.

### Código de ejemplo

```csharp
// Esto es un comentario: una nota para las personas. La compu lo ignora.
Console.WriteLine("Hola, soy Ceci.");
Console.Write("Primera nota: ");
Console.WriteLine("do sostenido");
Console.WriteLine(2 + 3);
```

### Salida esperada

```
Hola, soy Ceci.
Primera nota: do sostenido
5
```

### ¿Para qué sirve?

Todo programa, hasta el juego más grande hecho con Unity, está hecho de órdenes simples como estas, una después de la otra.

### Errores habituales

- **Olvidarse el `;`:** el error más común de todos. El compilador te dice la línea.
- **Escribir `console` con minúscula:** C# no lo reconoce.
- **Olvidarse una comilla:** el texto no termina nunca, y el compilador se queja.

### Micro-misión R00-N01-P4 · El slime desafinado

```meta
lugar: La Sala de Ensayo
personajes: Ceci, Gheco
criatura: slime
carta: Leer un error | Programa.cs(línea,columna) dice dónde mirar · CS1002: falta el ;
recompensa: xp 10, oro 10, monedas 3
```

#### Escena
De una partitura mal escrita sale un slime violeta, chiquito, que hace un ruido espantoso. Ceci se tapa los oídos. —Se llama error de sintaxis —dice Gheco—. Tranquila: el compilador te dice dónde está.

#### Gheco sugiere
Si tocás *Ejecutar* con un error, el programa no arranca y aparece algo así:

```
Programa.cs(2,27): error CS1002: Se esperaba ;
```

El primer número es **la línea**: ahí hay que mirar. `Se esperaba ;` quiere decir que falta un punto y coma. Sin ese `;`, ninguna orden se ejecuta, ni siquiera las que estaban bien.

#### Desafío
Tocá *Ejecutar* para ver el error. Después agregá lo que falta para que el programa funcione.

#### Código inicial
```csharp
Console.WriteLine("Afinando");
Console.WriteLine("Listo")
```

#### Salida esperada
```
Afinando
Listo
```

#### Solución
```csharp
Console.WriteLine("Afinando");
Console.WriteLine("Listo");
```

#### Al superarla
El slime hace *plop* y desaparece. Ceci se ríe: leyó un error por primera vez, y no era tan terrible.

#### Imagen
- Una hoja de partitura sobre un atril con un slime chiquito violeta y blando saliendo de ella.
- Ceci se tapa los oídos con cara graciosa; Gheco señala la hoja con la colita.

### Micro-misión R00-N01-P5 · La compu también hace cuentas

```meta
lugar: La Sala de Ensayo
personajes: Ceci, Bemol
carta: Texto y números | "2 + 3" es un texto y se muestra tal cual · 2 + 3, sin comillas, es una cuenta: da 5 · // es un comentario

```

#### Escena
—¿Cuántos compases llevamos? —pregunta Bemol, contando con los palillos—. Dejá, que lo cuente la compu. Para eso está.

#### Gheco sugiere
Con comillas es **texto**, y se muestra tal cual. Sin comillas es una **cuenta**, y se muestra el resultado:

```csharp
Console.WriteLine("1 + 1");
Console.WriteLine(1 + 1);
```

La primera muestra `1 + 1`, y la segunda muestra `2`.

Una línea que empieza con `//` es un **comentario**: una nota para las personas, que la compu ignora.

#### Desafío

#### Código inicial
```csharp

```

#### Salida esperada
```

```

#### Solución
```csharp
Console.WriteLine("Compases:");
Console.WriteLine(4 + 4);
```
